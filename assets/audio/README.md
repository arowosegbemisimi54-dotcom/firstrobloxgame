These WAV files are original procedural audio generated by
scripts/generate_radio_audio.py. No recordings, video audio, music samples or
voice likenesses were used. They are dedicated to the public domain under CC0.

- original-radio-static.wav: soft radio noise bed, 12 seconds.
- original-diner-babble.wav: three synthetic, nonverbal background voices, 18 seconds.
- original-radio-squelch.wav: a short transmitter release, 0.22 seconds.

Roblox cannot play repository WAV paths directly. Import these through Creator
Dashboard / Studio Asset Manager, grant the experience permission, then set the
returned rbxassetid values in DinerAudio.assets. The game currently uses quiet
platform cue/TTS fallbacks until those IDs are configured. Plot dialogue still
uses Roblox TTS; EscapeAudio.recordings accepts original actor recordings later.
